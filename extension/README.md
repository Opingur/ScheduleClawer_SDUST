# 课表导出器浏览器插件（MVP）

这是面向 Chrome / Edge 的 Manifest V3 开发版。它只在用户主动点击“导出当前课表”后读取当前标签页，不保存账号、密码、Cookie 或完整课表。

## 当前能力

1. 用户自行登录教务系统，并打开已经查询完成的“全部周次”课表。
2. 点击浏览器工具栏中的插件图标，填写学期总周数和第 1 周周一。
3. 点击“读取当前页面并导出 Excel”。
4. 插件在浏览器本地生成 Excel；不经过本项目服务器。

第一版包含 `generic-course-card-v1` 通用适配器：复用已验证的课表卡片解析与 Excel 排版逻辑，优先兼容山科教务系统页面，同时尝试识别含星期、教师、时间、地点字段的常见课表表格。后续平台/学校规则将以独立适配器加入。

## 本地安装（开发测试）

### Chrome / Edge

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择**包含 `manifest.json` 的插件文件夹**。若使用发布的测试压缩包，请先解压，再选择解压后的 `浏览器插件测试版` 文件夹。
5. 打开任一已登录并显示课表的网页，点击工具栏拼图图标，将“课表导出器”固定后使用。

## 权限说明

- `activeTab`：只在用户点击插件时临时访问当前标签页。
- `scripting`：把本地的导出脚本注入当前课表页。
- `storage`：只保存“总周数”和“第 1 周周一”两项非敏感设置。

插件不申请 `cookies`、`webRequest`、`tabs` 或全站点访问权限。它不会自动登录、绕过验证码或跨域限制。

## 后续适配

不同学校即使使用同一教务平台，也可能修改课表的 DOM、iframe、时间格式与周次规则。后续将通过“平台/学校适配器 + 通用识别器”扩展支持范围；不能承诺所有页面自动识别成功。
