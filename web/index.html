课表导出器 网页版

在已登录的教务系统课表页中读取“全部周次”，直接在浏览器本地生成 Excel。

不收集账号与密码。 本页不提供学校登录，也不保存课表；导出只在你的浏览器内完成。新建的书签固定指向公开的版本提交，不会被网页后续更新悄悄替换。

使用步骤

首次只需添加一次书签工具
  1. 1在浏览器中正常登录 WebVPN 与教务系统。
  2. 2进入“培养服务 → 我的课表 → 学期理论课表”，将周次设为“全部”后点击查询。
  3. 3按下方提示把“导出山科课表”拖进收藏栏。
  4. 4回到已显示课表的标签页，点击该收藏，即可下载 Excel。

导出书签

请使用桌面浏览器
↧ 导出山科课表

拖动上面的按钮到浏览器收藏栏，然后在课表页面点击它。

Chrome / Edge：按 Ctrl + Shift + B 显示收藏栏。Safari 可将按钮拖到收藏栏。

无法拖动书签？

先点击“复制书签代码”，新建一个浏览器收藏，将复制的内容粘贴到收藏的网址（URL）栏。请不要把它粘贴到教务系统的地址栏执行。

使用限制与排错

  • 必须在“学期理论课表”已显示、周次为“全部”的页面点击书签。
  • 若学校页面改版、出现验证码或浏览器阻止脚本，请保留截图和页面地址反馈，不要发送密码、Cookie 或完整课表。
  • 书签必须在当前课表页面以页面权限运行；学校若启用严格 CSP，或课表位于跨域 iframe，浏览器会阻止读取。纯静态网页无法绕过该限制。
  • 网页可在任意现代浏览器打开；书签导出主要支持 Chrome、Edge、Safari 等桌面浏览器。
