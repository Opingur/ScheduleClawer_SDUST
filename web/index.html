课表导出器 网页版

在已登录的教务系统课表页中读取“全部周次”，直接在浏览器本地生成 Excel。

不收集账号与密码。 本页不提供学校登录，也不保存课表；导出只在你的浏览器内完成。书签只加载本项目公开的导出代码；网页更新后，点击“更新书签设置”即可获得最新版。

推荐

安装到桌面

在支持的电脑浏览器中安装后，桌面和开始菜单会出现“山科课表导出器”，双击即可打开。

此入口会在支持安装网页应用的浏览器中显示。

下载双击启动器

下载一次即可。以后双击该文件，会用默认浏览器打开最新版网页。

下载网页版启动器
最简单

收藏本网页

把当前网页加入浏览器收藏夹，以后点收藏即可进入，不需要安装任何程序。

使用步骤

首次只需添加一次书签工具
  1. 1在浏览器中正常登录 WebVPN 与教务系统。
  2. 2进入“培养服务 → 我的课表 → 学期理论课表”，将周次设为“全部”后点击查询。
  3. 3按下方提示把“导出山科课表”拖进收藏栏。
  4. 4回到已显示课表的标签页，点击该收藏，即可下载 Excel。

导出设置

这些信息仅写入书签，不会上传

把“一键导出按钮”放进收藏栏

请使用电脑浏览器

它不是插件，也不需要安装。把下面的蓝色按钮拖进浏览器顶部的“收藏栏”，以后在课表页点一下它，就会下载 Excel。

第 1 步

先显示浏览器收藏栏

Chrome / Edge / 360 / QQ / 夸克电脑端：先按 Ctrl + Shift + B；没有反应时，点右上角菜单，查找“收藏 / 书签”并开启“显示收藏栏”。

Firefox：右键浏览器顶部空白处 → 勾选“书签工具栏” → 选择“始终显示”。

第 2 步

按住蓝色按钮，拖到收藏栏

↧ 导出山科课表 → 收藏栏

看到收藏栏里出现“导出山科课表”，就添加成功了。

第 3 步

回到课表页，点击收藏栏里的它

先确认“学期理论课表”已经显示、周次是“全部”，再点击收藏栏中的“导出山科课表”。Excel 会自动下载。

360、QQ、夸克用户请注意
  • 360 安全浏览器：请使用“极速模式”（闪电图标），不要使用兼容模式。
  • QQ / 夸克电脑端：一般可按 Chrome 的方式操作；若拖动无效，使用下方“复制按钮代码”新建收藏。
  • 手机 App：可以打开本网页，但大多数手机浏览器不能稳定添加或运行此类收藏栏按钮；请用电脑浏览器导出。
  • 安全软件拦截：若浏览器禁止 `javascript:` 收藏，纯网页无法绕过，建议换 Chrome、Edge 或 Firefox 电脑端。
“复制按钮代码”怎么用？

新建一个浏览器收藏，在“名称”填“导出山科课表”，在“网址 / URL”一栏粘贴复制的内容并保存。Firefox 也支持这种方式。请不要把代码粘贴到教务系统地址栏。

使用限制与排错

  • 必须在“学期理论课表”已显示、周次为“全部”的页面点击书签。
  • 若学校页面改版、出现验证码或浏览器阻止脚本，请保留截图和页面地址反馈，不要发送密码、Cookie 或完整课表。
  • 书签必须在当前课表页面以页面权限运行；学校若启用严格 CSP，或课表位于跨域 iframe，浏览器会阻止读取。纯静态网页无法绕过该限制。
  • 网页可在任意现代浏览器打开；书签导出主要支持 Chrome、Edge、Firefox、Safari、360、QQ、夸克等桌面浏览器。
